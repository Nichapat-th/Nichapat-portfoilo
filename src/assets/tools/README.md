# Design Tool Logos

Place your design tool logo images here:

- `figma.png` - Figma logo
- `sketch.png` - Sketch logo
- `photoshop.png` - Adobe Photoshop logo
- `miro.png` - Miro logo
- `canva.png` - Canva logo

After adding the images, uncomment the import statements in `src/data/designTools.js` and update the logo references.
