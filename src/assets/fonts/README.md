# LINE Seed Sans Font Files

To use LINE Seed Sans font, please download the font files from the official LINE Seed website:

**Download Link:** https://seed.line.me/index_en.html

## Steps:

1. Visit https://seed.line.me/index_en.html
2. Download the LINE Seed Sans font files
3. Extract the font files
4. Place the following font files in this directory:
   - `LINESeedSans-Regular.woff2` (or `.woff`)
   - `LINESeedSans-Medium.woff2` (or `.woff`)
   - `LINESeedSans-Bold.woff2` (or `.woff`)

## Alternative: Using TTF files

If you have TTF files instead, you can convert them to WOFF2 format using online tools like:
- https://cloudconvert.com/ttf-to-woff2
- https://convertio.co/ttf-woff2/

Or rename the font-face declarations in `src/styles/index.css` to use `.ttf` format instead.
